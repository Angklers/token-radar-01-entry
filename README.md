A token launch radar: it fits an implied-value line on the traded tokens in a frozen DefiLlama snapshot (log market cap on log TVL, one protocol per ticker, validated blind in five folds), ranks 200 pre-token protocols by that value with an 80% range, and gives each one a farm verdict with the expected net value and a seven-step farm plan, in a static dashboard that runs with no network.

## Run it

```sh
node main.ts --input <snapshot> 
```
